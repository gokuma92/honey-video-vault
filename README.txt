꿀곰 영상 보관함 - 공유 대상 PWA 버전

1. 압축 파일 안의 모든 파일을 새 GitHub Pages 저장소의 최상위에 업로드하세요.
2. Settings > Pages > Deploy from branch > main / root로 게시하세요.
3. 게시된 HTTPS 주소를 갤럭시 Chrome으로 열어 [⋮] > [홈 화면에 추가] > [설치]를 선택하세요.
4. 인스타·유튜브 앱에서 공유 > 더보기 > 영상 보관함을 선택해 링크를 전달하세요.
5. 열린 입력 화면에서 영상 저장하기를 누르세요.

주의: 단순 HTML 파일이나 Chrome 북마크 바로가기로는 공유 대상 등록이 되지 않을 수 있습니다. 설치된 PWA여야 합니다.
영상 기록은 동일 웹사이트 주소를 사용하는 해당 기기의 브라우저 저장소(localStorage)에만 저장됩니다. 기존 로컬 파일에 입력한 데이터는 자동 이전되지 않으므로 기존 버전에서 백업 후 새 사이트에서 가져오세요.
